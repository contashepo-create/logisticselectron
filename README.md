# 🚛 نظام المحاسبة وإدارة النقل واللوجستيات لسطح المكتب (Desktop Logistics & Accounting Pro)

نظام محاسبي وإداري متكامل مصمم لشركات ومؤسسات النقل البري والخدمات اللوجستية، مبني بتقنيات **Electron + React + TypeScript + Tailwind CSS**، ويعمل بكفاءة وسرعة فائقة أوفلاين **100% دون اشتراط اتصال دائم بالإنترنت**، مع التوافق التام مع **Windows 7 وما بعده (32 بت و 64 بت)**.

---

## 🌟 الميزات الرئيسية للنظام

### 1. 🖥️ تطبيق سطح المكتب (Desktop & Windows 7+ Compatibility)
- متوافق مع نظام تشغيل **Windows 7، 8، 8.1، 10، 11** بفضل ضبط إصدار Electron 22 وإعدادات التوافق الرسومية المناسبة.
- قاعدة بيانات محلية مدمجة مع نظام تصدير واستيراد النسخ الاحتياطية بصيغة **JSON**.
- واجهة مستخدم حديثة تدعم الوضع الداكن والفاتح بالكامل (**Dark / Light Mode**) مع خط عربي احترافي عالي الوضوح (**IBM Plex Sans Arabic**).

### 2. 📊 لوحة تحكم ومؤشرات قيادية (Executive Dashboard)
- مؤشرات مالية لحظية: إجمالي الإيرادات، التكاليف التشغيلية، صافي الأرباح، والسيولة النقدية.
- رسم بياني مرئي لتدفقات الإيرادات والمصروفات على مدار 6 أشهر.
- رصد مديونيات العملاء ومستحقات الموردين وحالة الأسطول وعدد النقلات المنفذة.
- شريط إجراءات سريعة وسجل مباشر لآخر الحركات والعمليات المالية.

### 3. 📄 6 قوالب طباعة فواتير + قالب تقارير موحد + سندات مالية
- **الفواتير:**
  1. `العصري الحديث (Modern Clean)`: تصميم افتراضي جذاب ومرتب.
  2. `الكلاسيكي الرسمي (Classic Official)`: ترويسة رسمية وجداول محاسبية معتمدة.
  3. `الضريبي المعتمد (ZATCA Standard)`: متوافق مع متطلبات هيئة الزكاة والضريبة والجمارك مع رمز الاستجابة السريع (QR Code TLV Base64).
  4. `الشحن اللوجستي (Logistics Detailed Cargo)`: يعرض تفاصيل الحاويات، أماكن التحميل والتعتيق، والمصروفات الإضافية.
  5. `إيصال حراري (Thermal 80mm Cashier)`: مناسب للطابعات الحرارية وإيصالات السائقين السريعة.
  6. `الملكي الأنيق (Royal Elegant)`: تصميم فاخر للعملاء الكبار.
- **التقارير الموحدة:**
  - قائمة الأرباح والخسائر والدخل التشغيلي (**P&L**).
  - كشوف حسابات العملاء والموردين التفصيلية مع الرصيد التراكمي المتحرك.
  - تقارير أعمار الديون (**Aging Reports 0-30, 31-60, 61-90, 90+**).
  - تقرير ربحية وكفاءة أسطول الشاحنات واستهلاك الوقود.
  - سجل حركة النقلات والشحنات.
- **السندات:**
  - سندات القبض المالية.
  - سندات الصرف ومصروفات الرحلات وصيانة المركبات.
  - مسيرات الرواتب وكشوف السلف والخصومات.
  - إشعارات الدائن والمدين.

### 4. 🔑 نظام التراخيص والتجربة المجانية (7-Day Trial & 30-Day Offline Operation)
- تجربة مجانية كاملة لمدة **7 أيام** تبدأ تلقائياً عند أول تشغيل للبرنامج.
- عند التفعيل بكود اشتراك يعمل البرنامج لمدة **30 يوماً أوفلاين** بالكامل دون طلب اتصال إنترنت.
- تنبيه غير مزعج يظهر عندما يتبقى **5 أيام أو أقل** يطلب الاتصال بالإنترنت لتجديد الترخيص.
- نافذة تفعيل مدمجة تدعم النسخ الفوري لكود الجهاز، والتواصل المباشر مع المطور عبر واتساب وتليجرام.

### 5. 🤖 الربط السحابي وبوت تليجرام المطور (Telegram Bot + Cloudflare)
- كود باك إند كامل وجاهز داخل `cloudflare-worker/worker.js` للنشر على **Cloudflare Workers**.
- واجهة محاكي تفاعلية لأوامر البوت داخل التطبيق:
  - `/start`: عرض دليل الأوامر.
  - `/about`: استعراض بيانات صفحة حول التطبيق الحالية.
  - `/set_name [الاسم]`: تعديل اسم التطبيق عن بعد.
  - `/set_phone [الرقم]`: تعديل رقم الاتصال.
  - `/set_whatsapp [الرقم]`: تعديل رقم واتساب.
  - `/set_about [النص]`: تعديل النبذة التعريفية.
  - `/set_price [شهري] [سنوي]`: تحديث أسعار الاشتراكات.
  - `/keygen [كود_العميل] [monthly|yearly|open]`: توليد كود تفعيل فوري معتمد.
  - `/subscribers`: عرض المشتركين وحالة تراخيصهم وأجهزتهم.
  - `/activate [كود_العميل] [المدة_بالأيام]`: تفعيل اشتراك عن بعد.
  - `/suspend [كود_العميل]`: إيقاف أو تعليق اشتراك عميل.
  - `/reply [كود_العميل] [الرسالة]`: إرسال رد مباشر من البوت إلى شات الدعم في تطبيق العميل.

### 6. 💬 شات الدعم الفني المباشر داخل التطبيق (Two-Way In-App Chat)
- قناة تواصل مباشرة يستطيع العميل من خلالها كتابة استفساراته أو إرسال طلبات التفعيل.
- تصل الرسالة فوراً للمطور، ويتمكن المطور من الرد عبر بوت تليجرام بأمر `/reply` ليصل الرد فوراً إلى شات التطبيق.

## 🛠️ دليل التشغيل والتطوير

### التثبيت والتشغيل المحلي
```bash
# تثبيت الحزم
npm install

# تشغيل خادم التطوير (Web Preview)
npm run dev

# تشغيل بيئة Electron لسطح المكتب
npm run electron:dev

# بناء حزمة الإنتاج لسطح المكتب لنظام Windows
npm run dist:win
```

### تشغيل الاختبارات الآلية
```bash
npm test
```
